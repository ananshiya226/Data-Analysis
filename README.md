# Train Schedule Analysis and Interactive Route Enquiry System

## 📌 Project Overview

This project was completed as part of the **Data Analyst Internship at Sysslan IT Solutions**.

The project focuses on analyzing train schedule data using **Python and Pandas** to clean, process, analyze, and visualize train information. It also includes an interactive train enquiry system for route-based train information.

## 🎯 Objectives

- Understand the structure and quality of the train dataset
- Perform data cleaning and preprocessing
- Calculate train journey durations
- Analyze train stops and station traffic
- Create visualizations to identify patterns and trends
- Perform advanced analysis using pivot tables and cross-tabulations
- Develop an interactive train enquiry system

## 📊 Project Levels

### Level 1 – Basic Data Review
- Dataset overview
- Starting and ending stations
- Number of stops per train
- Maximum and minimum stops

### Level 2 – Simple Data Processing
- Standardization of arrival and departure times
- Journey duration calculation
- Route classification
- Station-wise train frequency

### Level 3 – Data Quality Checks
- Missing value handling
- Duplicate record removal
- Station order verification
- Saving the verified dataset

### Level 4 – Analysis and Visualization
- Journey duration analysis
- High-traffic station identification
- Data visualization
- Key observations

### Level 5 – Advanced Analysis
- Station-wise pivot tables
- Station and route cross-tabulation
- Comparative visualizations
- Advanced insights

### Level 6 – Interactive Train Enquiry System
- Source and destination based train search
- Direct train availability
- Estimated journey duration
- Interactive user input

## 📁 Dataset

The project uses `Dataset1.csv` containing train schedule information including train numbers, station details, route information, arrival/departure times, distance, and other train-related attributes.
